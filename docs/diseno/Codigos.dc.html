Códigos de barras

Código desconocido en el punto de venta
La acción que se ejecuta con Enter.
Cuando el lector escanea un código que no está cargado, aparece una barra con tres opciones y la que elijas acá se ejecuta con solo apretar Enter. Alta rápida: cargás el producto en el momento. Borrador: se crea con lo mínimo y lo completás después. Producto X: se vende sin crear el producto, ideal cuando hay cola.
Cuando escaneás un código nuevo, Velora busca el nombre del producto para que no tengas que escribirlo. Solo se comparte el código y el nombre, nunca tus precios ni tus ventas. Sin internet, lo escribís a mano.
Te avisa sin mirar la pantalla: un pitido corto si encontró el producto, uno doble si es nuevo y uno grave si el código se leyó mal y hay que volver a escanear.
Si no tenés lector, apuntás el código a la cámara de la notebook o a una webcam. Es más lento que un lector USB, así que conviene usarlo solo como respaldo.
Las balanzas que imprimen etiquetas ponen dentro del código qué producto es y cuánto pesa (o cuánto cuesta). Activalo si usás una. Los valores de abajo sirven para la mayoría; si tu balanza usa otro formato, pegá un código real en "Probar" y ajustalos hasta que el resultado coincida con la etiqueta.
Prefijo: los primeros dígitos que marcan que es un código de balanza (casi siempre 20). Dígitos del producto: el número de producto (PLU) que cargaste en la balanza. Decimales: con 3, "00750" se lee como 0,750 kg.
